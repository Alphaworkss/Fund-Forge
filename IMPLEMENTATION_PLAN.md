# Implementation Plan — Multi-Asset AI Financial Forecasting & Paper Trading Platform (FinSight Intelligence)

Build a full-stack, production-quality **AI Financial Forecasting, Analysis, and Paper Trading Platform** ("FinSight Intelligence"). The system is architected as a universal financial platform supporting **Stocks**, **Cryptocurrencies**, **Mutual Funds**, and **Commodities** using an `AssetType` abstraction layer, responsive Stitch UI components, and mock-to-production provider factories.

## 1. Multi-Asset Architecture
The platform handles 4 core asset classes out of the box:
- **Stocks** (AAPL, NVDA, MSFT, AMZN, TSLA, GOOGL, META) with P/E, EPS, Market Cap, Dividend Yield, Sector/Industry metrics.
- **Cryptocurrencies** (BTC, ETH, SOL, BNB, XRP, ADA, DOGE, AVAX, LINK, DOT, MATIC, LTC, ATOM, UNI, NEAR) with Circulating Supply, Volume, BTC Dominance.
- **Mutual Funds** (Growth Index Fund, Balanced Wealth Fund, High Yield Income Fund) with NAV, AUM, Expense Ratio, Fund Manager, Asset Allocation (Equity/Debt/Cash).
- **Commodities** (Gold, Silver, WTI Crude Oil, Brent Crude, Natural Gas, Copper) with Troy Ounce/Barrel units, Contract Specs, Open Interest, Supply/Demand drivers.

## 2. Mock-to-Production Provider Pattern
Initial implementation uses deterministic mock data generated by FastAPI (`DATA_MODE=mock`), guaranteeing complete operational readiness across all 4 asset classes, charts, forecasts, explainability, news, and multi-asset paper trading without external DB or model dependencies.

## 3. Detailed File Structures & Components

### Backend — Python FastAPI Server (`backend/`)

Build a clean, modular FastAPI backend service with Pydantic validation, `AssetType` enum, provider abstraction layer, and deterministic multi-asset mock data providers.

- `backend/app/main.py`: FastAPI application entry point, CORS middleware (`http://localhost:3000`), router mounting (`/api`), and health check endpoint.
- `backend/app/config/settings.py`: Environment settings (`DATA_MODE`, `API_PREFIX`, `CORS_ORIGINS`).
- `backend/app/schemas/`:
  - `assets.py`: `AssetType` enum (`stock`, `crypto`, `mutual_fund`, `commodity`), `BaseAsset` schema, and metadata models (`StockMetadata`, `CryptoMetadata`, `MutualFundMetadata`, `CommodityMetadata`).
  - `market.py`: Market overview per asset class, top gainers/losers, indices.
  - `history.py`: Time series data points with unit & frequency tags.
  - `forecasts.py`: Upper/lower bounds, central estimate, direction, confidence, model name, asset_type, horizon (1d, 7d, 14d, 30d, 90d).
  - `models.py`: Model evaluation metrics (MAE, RMSE, R², MAPE) across PatchTST, TFT, LightGBM, XGBoost, ARIMA.
  - `features.py`: Asset-specific explainability factors & SHAP values.
  - `news.py`: Asset-tagged financial news feed.
  - `paper_trading.py`: Multi-asset portfolio state, trades, holdings, P&L, asset allocation breakdown.
- `backend/app/providers/base.py`: Abstract Provider Interfaces (`BaseAssetProvider`, `BaseMarketProvider`, `BaseForecastProvider`, `BaseModelProvider`, `BaseFeatureProvider`, `BaseNewsProvider`, `BasePaperTradingProvider`).
- `backend/app/providers/mock/`: Multi-asset mock providers for assets, market, history, forecasts, models, features, news, paper trading.
- `backend/app/api/routes/`: API endpoints for assets, market, history, forecasts, models, features, news, paper trading.
- `backend/requirements.txt`: Python dependencies (`fastapi`, `uvicorn`, `pydantic`, `pydantic-settings`, `python-dotenv`).

### Frontend — Next.js Application (`frontend/`)

Create a Next.js (App Router) TypeScript application styled with Tailwind CSS, custom Stitch design tokens, and Recharts visualization.

- `frontend/tailwind.config.ts`: Extend theme with `DESIGN.md` surface/primary/emerald/rose/mono color tokens.
- `frontend/app/globals.css`: CSS variables for Stitch dark theme, scrollbars, glassmorphism, fonts.
- `frontend/lib/api/`: Unified API client and types (`client.ts`, `types.ts`, `assets.ts`, `forecasts.ts`, `market.ts`, `history.ts`, `models.ts`, `features.ts`, `news.ts`, `paperTrading.ts`).
- `frontend/components/`:
  - `navigation/Navbar.tsx`: Top navigation bar, brand logo ("FinSight Intelligence"), active link indicator, Demo Mode badge.
  - `navigation/TickerRibbon.tsx`: Multi-asset ticker ribbon with real-time price updates.
  - `shared/AssetSelector.tsx`: Dropdown selector with Asset Class tab filtering.
  - `charts/PriceChart.tsx`: Universal price/NAV chart with historical line and AI forecast confidence band.
  - `charts/PortfolioChart.tsx`: Portfolio equity curve & asset allocation pie chart.
  - `charts/FeatureImportanceChart.tsx`: SHAP feature contribution bar chart.
  - `asset/`: Cards for Stock Fundamentals, Crypto Metrics, Mutual Fund Metrics, Commodity Specs.
  - `forecast/`: ForecastCard, HorizonPicker, ModelMetricsCard.
  - `portfolio/`: TradeModal, HoldingsTable, TransactionHistory.
- `frontend/app/`:
  - `layout.tsx`: Root layout with dark theme `#0b1326`, Inter & JetBrains Mono fonts, Navbar, TickerRibbon.
  - `page.tsx` (Dashboard Overview): Multi-asset selector, price/NAV chart, forecast overlay, model accuracy, SHAP explainability, news feed.
  - `forecasts/page.tsx`: Forecasting workspace with horizon picker, model comparison, forecast bounds table.
  - `paper-trading/page.tsx`: Multi-asset paper trading simulation dashboard.
  - `market/page.tsx`: Multi-asset market explorer with tabbed filtering.
  - `methodology/page.tsx`: AI forecasting methodology & model architecture overview.
